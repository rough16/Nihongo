𝗥𝗼𝘂𝗻𝗱 1 – 𝗧𝗲𝗰𝗵𝗻𝗶𝗰𝗮𝗹 𝗥𝗼𝘂𝗻𝗱:

Implementation: Design and implement a word auto-complete suggestion feature for keyboards.

Follow-up: Optimizing the Trie for memory and adding weightage/frequency to suggestions.
